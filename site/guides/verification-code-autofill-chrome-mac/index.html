Code autofill not working in Chrome on Mac

Why text message codes don’t appear in Chrome and other browsers on a Mac, and what to do about it.

On an iPhone, a code from a text message appears above the keyboard. On a Mac it is less dependable, and in Chrome it often does not appear at all. Here is what is going on and what to do.

Short answer: before macOS 26, codes only autofill in Safari. On macOS 26, update to the latest version. Or skip autofill and paste the code, which works everywhere.

What works where

SafariChrome, Firefox, Arc, Edge
macOS 15 and earlierYesNo
macOS 26.0 and 26.1YesBroken for many people
macOS 26.2 and laterYesReported working again

The last two rows come from user reports, linked below. Your version may behave differently.

First: which macOS do you have?

Open Apple menu → About This Mac.

  • macOS 15 or earlier: codes autofill in Safari only. Chrome, Firefox, Arc and Edge never offered them, so nothing is broken. Skip to the way that works on any version.
  • macOS 26 (Tahoe): Apple added code autofill for other browsers, as MacRumors reported. Then it stopped working for many people. Read on.

1. Check the code reaches your Mac

Open Messages on your Mac and ask for a new code. If the text does not show up there, no browser can fill it.

For codes sent by SMS, turn on forwarding on your iPhone: Settings → Apps → Messages → Text Message Forwarding, then switch on your Mac. Both devices must use the same Apple Account.

If it still does not arrive, check three things:

  • The iPhone is switched on and online. It is the one that receives the SMS.
  • Messages on the Mac is signed in: Messages → Settings → iMessage.
  • Your Mac is ticked in the Text Message Forwarding list on the iPhone.

2. Update macOS 26

In late 2025, people on Apple’s support forum found that codes had stopped appearing in Chrome, Firefox, Brave and Opera on macOS 26, while Safari kept working. They later reported it fixed in a newer release, and a MacRumors forum thread says codes came back in Chrome with macOS 26.2.

So: System Settings → General → Software Update, and install what is offered.

3. Things people report, with a warning

  • Siri and Apple Intelligence. Some people say suggestions stopped when these were off, and returned when they turned them back on.
  • A Terminal setting. The forum thread names a hidden setting that brings autofill back on affected versions. The same thread says it caused slowdowns and crashes in Chrome-based apps, so we do not recommend it. Updating is the safer fix.

I have not tested these on every version. They come from the threads linked above.

Why some pages never offer the code

Even when everything is set up, the browser only offers a code in a field it recognises as a code field. Websites mark such a field for the browser. Many do not, and then no suggestion appears, in Safari or anywhere else. There is nothing you can change on your side.

4. The way that works on any version

Autofill depends on your macOS version, your browser and the page. Pasting does not. If the code is already on your clipboard, ⌘V works in every browser and every app.

That is what CodeCatch does. It reads the code from Messages or your email as it arrives, copies it, and shows it in a small banner. It works on macOS 15 and later.

Without CodeCatch, you can do the same by hand: open Messages on your Mac, double-click the code, copy, switch back and paste.

Questions

Why does Safari fill the code when Chrome doesn’t?

Code autofill is a macOS feature that Apple built into Safari first. Other browsers only got access with macOS 26, and it has been unreliable there.

Do I need an iPhone?

For codes sent by SMS, yes. The iPhone receives the text and forwards it to your Mac. With an Android phone the text never reaches Messages on the Mac, so neither autofill nor CodeCatch can see it.

What about codes sent by email?

macOS can suggest codes from the Mail app in Safari. It does not read Gmail in your browser. CodeCatch reads Apple Mail, Gmail and other mail accounts directly.

The code arrives late on my Mac. Why?

SMS codes go to your iPhone first and are then forwarded. The iPhone has to be switched on and online. Keeping Messages open on the Mac helps.

Is it safe to let codes fill in by themselves?

A code is only as safe as the page it goes into. Before you ask for one, check the address bar. That holds for autofill and for pasting alike.
