CodeCatch vs MessAuto

Short answer: MessAuto is the better pick if you want a free tool that pastes the code and presses Return. CodeCatch is the better pick if your codes arrive in Gmail, if you get sign-in links, or if you want to find a code again later.

What is MessAuto?

MessAuto is a free, open-source menu bar app for the Mac, written in Rust by LeeeSe. It watches the Messages and Mail apps. When a message contains a verification code, MessAuto copies it, and can paste it into the field you are in and press Return.

It is a well-liked project: about 1,600 stars on GitHub in October 2026, under the MIT licence. The latest release, 1.3.0, came out in October 2025.

What the two apps share

  • They work in any app. Neither depends on browser autofill, so Chrome, Arc, Firefox and Edge all work. If that is your problem, see why code autofill fails in Chrome on Mac.
  • They read Messages and the Mail app. SMS codes reach either app only after you turn on Text Message Forwarding on your iPhone.
  • They need Full Disk Access. macOS requires it before any app can read Messages and Mail.
  • They are open source and run on your Mac, with no account.

Where MessAuto is stronger

  • It is free.
  • Hands-off entry. Auto Paste puts the code in the field, and Auto Return submits it. You do not touch the keyboard.
  • It can leave your clipboard alone. In its “Don’t Occupy Clipboard” mode, MessAuto types the code directly, so what you copied earlier stays put.
  • A window by your cursor. Its floating window shows the code next to the pointer.
  • Your own rules. A config file lets you edit the keywords and patterns MessAuto uses to spot a code.

Where CodeCatch is stronger

  • Gmail and other mail, directly. MessAuto reads the Mail app only, and its README lists other mail clients as not yet supported. CodeCatch reads the Mail app, and also connects to Gmail and other accounts with an app password. Mail stays read-only.
  • Sign-in links. Many services now send a link in place of a code. CodeCatch shows the link next to your codes, tells you where it goes, and warns you if it leads to a different site than the sender’s.
  • History. Codes and links stay in the menu for seven days. Type a name, press Return, and the code is copied again.
  • Bitwarden codes. CodeCatch shows your Bitwarden codes in the menu bar, locked with Touch ID.
  • Fewer permissions by default. CodeCatch asks for Accessibility access only if you want it to type codes for you.
  • A normal install. CodeCatch is signed with a Developer ID, so it opens like any other app.

Accessibility access lets an app press keys in other apps. That is what makes auto-paste possible, and it is why CodeCatch leaves it off until you ask for it.

Installing each one

Both are a download from GitHub. MessAuto is not signed by an identified developer, so macOS refuses to open it the first time. Its README gives two ways around that: right-click the app and choose Open, or switch off the check for all apps in Terminal.

If you install MessAuto, use the right-click route. Switching off the check with spctl --master-disable removes that protection for every app on your Mac, not just one.

Switching from MessAuto to CodeCatch

  • Quit MessAuto from its menu bar icon, so two apps do not react to the same code.
  • Download CodeCatch and open it. It sits in the menu bar.
  • Allow Full Disk Access. CodeCatch opens the setting for you.
  • Add mail. Switch on Apple Mail, or add Gmail with an app password.
  • Miss auto-paste? Turn on typing codes for you in Settings. macOS will then ask for Accessibility access.

Questions

What is MessAuto?

MessAuto is a free, open-source Mac app that finds verification codes in the Messages and Mail apps and puts them where you need them. It can copy the code, paste it for you, and press Return.

Is MessAuto free?

Yes. MessAuto is free and open source under the MIT licence. You download it from its GitHub page.

Does MessAuto work with Gmail?

Only if your Gmail account is set up in the Mac’s Mail app. MessAuto reads the Mail app, not Gmail itself, and its README lists other mail clients as not yet supported. CodeCatch reads the Mail app too, and can also connect to Gmail and other accounts directly.

Does MessAuto work in Chrome?

Yes. Like CodeCatch, it works through the clipboard and keyboard, so the browser does not matter. Both work in Chrome, Arc, Firefox, Edge and any other app.

Which permissions does each app need?

Both need Full Disk Access, because macOS requires it before any app can read Messages and Mail. MessAuto’s README also lists Accessibility access, which lets an app type into other apps. CodeCatch asks for Accessibility only if you turn on typing codes for you.

Can I use MessAuto and CodeCatch together?

You can, but both will react to the same code. If you run both, leave pasting to one of them: keep MessAuto’s Auto Paste on and CodeCatch’s typing off, or the other way round.

What is a good MessAuto alternative?

If you want what MessAuto does plus Gmail, sign-in links, a searchable history and Bitwarden codes, try CodeCatch. If you only get codes by text message, 2FHey is another open-source option.
