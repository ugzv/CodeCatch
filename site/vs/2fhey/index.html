Short answer: 2FHey is the better pick if your codes only come by text message, or if you use Google Messages. CodeCatch is the better pick if codes also reach you by email, if you get sign-in links, or if you want to find a code again later.

What is 2FHey?

2FHey is an open-source menu bar app for the Mac, written in Swift by SoFriendly. It watches for incoming text messages. When one contains a verification code, 2FHey copies the code and shows a notification, so you can paste it in any browser.

It does one job and stays small: its website says the app is under 10 MB. The code is on GitHub, where it was still being updated in August 2026.

What the two apps share

  • They work in any app. Both put the code on your clipboard, so Chrome, Arc, Firefox and Edge all work. Neither depends on browser autofill. If that is your problem, see why code autofill fails in Chrome on Mac.
  • They read iMessage and SMS from the Messages app on your Mac.
  • They need Full Disk Access. macOS requires it before any app can read Messages.
  • They can paste for you, if you turn that on.
  • They are open source and work on your Mac, with no account.

Where 2FHey is stronger

  • Google Messages. Its website lists Google Messages next to iMessage. CodeCatch needs the text to reach the Messages app, which takes an iPhone.
  • One shortcut to fetch the last code. ⇧⌘E rereads your messages and copies the latest code again.
  • It is simple. No mail accounts to add and few settings to learn.
  • Detection rules anyone can extend. Its keyword files live on GitHub, and the app fetches the newest ones each time it starts.

Where CodeCatch is stronger

  • Email codes. 2FHey reads text messages only. Reading Apple Mail has been an open request on its GitHub page since 2023. CodeCatch reads Apple Mail, and connects to Gmail and other accounts with an app password. Mail stays read-only.
  • Sign-in links. Many services now send a link in place of a code. CodeCatch shows the link next to your codes, tells you where it goes, and warns you if it leads to a different site than the sender’s.
  • History. Codes and links stay in the menu for seven days. Type a name, press Return, and the code is copied again.
  • Bitwarden codes. CodeCatch shows your Bitwarden codes in the menu bar, locked with Touch ID.
  • More languages. CodeCatch recognises codes in 35 languages. 2FHey’s README lists six.
  • Fewer permissions by default. CodeCatch asks for Accessibility access only if you want it to type codes for you.

Accessibility access lets an app press keys in other apps. That is what makes auto-paste possible, and it is why CodeCatch leaves it off until you ask for it.

Switching from 2FHey to CodeCatch

  • Quit 2FHey from its menu bar icon, so two apps do not copy the same code.
  • Download CodeCatch and open it. It sits in the menu bar.
  • Allow Full Disk Access. CodeCatch opens the setting for you.
  • Add mail. Switch on Apple Mail, or add Gmail with an app password. This is the part 2FHey does not have.
  • Used auto-paste? Turn on typing codes for you in Settings. macOS will then ask for Accessibility access.

Questions

What is 2FHey?

2FHey is an open-source Mac app that spots verification codes in incoming text messages and copies them to your clipboard, so you can paste them in Chrome, Firefox, Arc or any other app.

Does 2FHey work with email codes?

No. 2FHey reads text messages only. Reading codes from Apple Mail has been an open feature request on its GitHub page since 2023. CodeCatch reads Apple Mail, Gmail and other mail accounts.

Does 2FHey work with Google Messages?

Its website says it does, next to iMessage. CodeCatch reads the Messages app on your Mac, so SMS codes need an iPhone with Text Message Forwarding turned on.

Is 2FHey free?

2FHey is open source, and its README says the download goes through Gumroad. Check its website for the current price.

Does 2FHey work in Chrome and Firefox?

Yes. Like CodeCatch, it copies the code to the clipboard, so it works in any browser and any app.

Which permissions does each app need?

Both need Full Disk Access to read Messages. 2FHey’s README also lists Accessibility access, for auto-paste and its keyboard shortcut. CodeCatch asks for Accessibility only if you turn on typing codes for you.

Can I use 2FHey and CodeCatch together?

You can, but both will copy the same text message code. A simple split is to let one app handle text messages and switch that source off in the other.

What is a good 2FHey alternative?

If you want what 2FHey does plus codes from email, sign-in links, a searchable history and Bitwarden codes, try CodeCatch. If you want a free tool that also reads Apple Mail and pastes for you, MessAuto is another open-source option.
