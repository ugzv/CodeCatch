Changelog

What’s new in CodeCatch

Newest first. CodeCatch 1.0 is still being finished, so this is what has been built so far.

6 October 2026

Latest

Unlock with your Mac
A new switch in Settings → Privacy. Turn it on and CodeCatch unlocks whenever your Mac does, with no Touch ID prompt. It is off unless you turn it on.
Password reset links
Caught apart from sign-in links, with their own switch in Settings → Sources. A “password changed” alert is not mistaken for one.
A warning on every risky link
When a link leads to a different site than the sender’s, the warning now shows in the list too, in full.
Clearer unlock errors
If unlocking fails, CodeCatch says why, where you clicked. Closing the password prompt stays quiet.
Asks before removing
Remove Account, Remove Bitwarden Codes and Clear History ask first.
Sharper logos
More services show their own logo, including small sites.
Mail codes on time
A code that arrived just as CodeCatch started watching your inbox no longer waits for the next email.
Plainer wording
Messages, errors and settings are shorter and easier to read. Errors look the same everywhere, and VoiceOver reads codes in the list digit by digit.

4 October 2026

  • Apple Mail No sign-in needed
  • Automatically Type CodesInto the focused field, while unlocked
Apple Mail
Read codes from the inboxes already set up in the Mail app, with no sign-in.
Automatically Type Codes
An optional setting, off by default, that types a new code into the field you are in.
One lock for every code
Codes stay hidden until you unlock with Touch ID or your Mac password, and stay out of search, the clipboard and the menu bar.
Simpler Settings
Three tabs: General, Sources and Privacy. Each switch sits next to what it controls.
Report a bug from the app
The ? button in Settings opens a GitHub bug report with your CodeCatch version and Mac already filled in.
Sign-in links open as sent
Some links lost part of their address and opened an error page. They now open exactly as the email wrote them.
Choose what to catch
Switch verification codes, sign-in links and Bitwarden codes on or off separately.
Can’t find your code?
A window that shows recent verification emails where no code was found, so you can copy it by hand.
Automatic updates
CodeCatch checks for a new version once a day and installs it. Check by hand or switch it off in Settings → General.
Counted installs
Update checks now send a random install ID, the app version, the macOS version and the Mac model, so we can see how many Macs run each version. They never include your codes or what you do in the app. The privacy page has the details.
Apple silicon and Intel
One build for both. The menu now shows the app version.
