Pourquoi cette app

J’en avais assez de chercher mes codes

Chaque connexion, la même corvée. Attendre le code. Prendre mon téléphone. Regarder dans Messages, puis dans chacun de mes comptes e-mail. Le remplissage automatique des codes du Mac aidait parfois, mais trop souvent rien ne s’affichait.

Alors j’ai créé l’app que je voulais : un seul endroit sur mon Mac où chaque code s’affiche dès son arrivée. Je suis Uros Gazvoda, et je développe CodeCatch seul. Chaque modification est publiée sur GitHub, avec son explication.

Questions fréquentes

Les agents IA comme Claude Code peuvent-ils obtenir mes codes ?

Seulement si vous l’activez dans CodeCatch, sous Settings → Agents. Un agent n’obtient alors qu’un code à la fois, pour le site qu’il demande. Vous validez chaque code avec Touch ID, sauf si vous autorisez un site ou activez Allow All. Les agents ne voient jamais vos messages. Comment ça marche.

CodeCatch fonctionne-t-il dans Chrome, Arc et Firefox ?

Oui. Chaque nouveau code est copié : vous le collez avec ⌘V dans n’importe quel navigateur ou app.

Quelle différence entre CodeCatch et le remplissage automatique de macOS ?

Depuis macOS 26, un code reçu dans Messages ou Mail s’affiche près du curseur dans la plupart des apps, pendant les 3 minutes qui suivent son arrivée. Sous macOS 15, il ne s’affiche que dans les champs prévus pour cela. Le menu d’un gestionnaire de mots de passe peut aussi masquer la suggestion. Pour les codes reçus par e-mail, macOS n’utilise que l’app Mail, qui doit être ouverte pour recevoir les nouveaux messages. CodeCatch copie chaque code dès son arrivée, donc ⌘V marche dans n’importe quel champ. Il lit aussi Gmail et Outlook directement, récupère les liens de connexion, garde un historique et affiche vos codes Bitwarden. Si le remplissage automatique ne marche plus chez vous, lisez notre guide sur le remplissage automatique.

Quels comptes e-mail CodeCatch peut-il lire ?

Toutes les boîtes configurées dans Apple Mail, sans connexion supplémentaire. Gmail, Outlook et les autres comptes (IMAP) aussi. CodeCatch les lit lui-même, donc Mail peut rester fermé. CodeCatch ne fait que lire : il ne marque, ne déplace et ne supprime jamais vos e-mails.

Pourquoi CodeCatch a-t-il besoin de l’accès complet au disque ?

macOS l’exige avant qu’une app puisse lire Messages et Apple Mail. Pour Messages, Apple n’offre pas d’autre moyen. CodeCatch ne lit que ces deux-là et n’y modifie jamais rien. Vos codes restent sur votre Mac. Si vous préférez ne pas l’accorder, désactivez Messages dans CodeCatch. Gmail, Outlook et les autres comptes e-mail n’en ont pas besoin. Il n’a besoin de l’accès Accessibilité que si vous activez l’option qui tape les codes pour vous.

Est-ce que des données quittent mon Mac ?

Les codes et les messages restent sur votre Mac, et les mots de passe dans votre trousseau. CodeCatch se connecte aux services e-mail que vous avez activés et vérifie les mises à jour sur codecatch.app. Si vous vous connectez avec Google ou Microsoft, il communique avec eux. L’import Bitwarden communique avec Bitwarden. Les logos se chargent via le service de favicons de Google ou de DuckDuckGo. Vous pouvez désactiver les logos dans l’onglet Privacy de CodeCatch.

Quelle configuration faut-il pour CodeCatch ?

macOS 15 ou version ultérieure, sur un Mac avec puce Apple ou Intel. Pour recevoir les codes SMS sur votre Mac, activez le Transfert de SMS sur votre iPhone.

Les codes reçus par SMS n’apparaissent pas. Que vérifier ?

Votre Mac ne reçoit que les SMS que votre iPhone lui transfère. Sur l’iPhone, ouvrez Réglages → Apps → Messages → Transfert de SMS et activez votre Mac. Si l’option ou votre Mac n’apparaît pas, vérifiez que les deux appareils utilisent le même compte Apple (sur le Mac : Messages → Réglages → iMessage). Désactivez ensuite iMessage sur l’iPhone, puis réactivez-le. L’iPhone doit aussi être allumé et connecté à Internet. Autres solutions.

Et si CodeCatch rate un code ?

Signalez-le sur GitHub. Joignez le message en remplaçant le code par un autre nombre. Ce message devient un test, et la version suivante reconnaîtra ce code.

CodeCatch existe-t-il en français ?

Ce site, oui. L’app elle-même n’existe pour l’instant qu’en anglais. Elle reconnaît quand même les codes dans vos messages et e-mails en français, par exemple quand ils parlent de « code de vérification », de « code de validation » ou de « code de sécurité ». Au total, CodeCatch reconnaît les codes dans 35 langues.
