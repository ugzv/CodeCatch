Why it exists

I got tired of hunting for codes

Every sign-in was the same chore. Wait for the code. Pick up my phone. Check Messages, then each of my mail accounts. The Mac’s own code autofill helped sometimes, but too often it never showed up.

So I built the app I wanted: one place on my Mac where every code shows up the moment it arrives. I’m Uros Gazvoda, and I build CodeCatch on my own. Every change is on GitHub, with the reason for it.

Questions

Does CodeCatch work in Chrome, Arc and Firefox?

Yes. Each new code is copied, so you can paste it in any browser or app with ⌘V.

How is CodeCatch different from macOS autofill?

macOS only suggests a code in fields that support it. CodeCatch copies every code, so it works everywhere. It also reads Gmail, catches sign-in links, keeps a history and shows your Bitwarden codes. If autofill stopped working for you, see the autofill guide.

Which mail accounts can CodeCatch read?

Any inbox set up in Apple Mail, with no sign-in. Also Gmail and other accounts (IMAP), with an app password. CodeCatch only reads: it never marks, moves or deletes mail.

Why does CodeCatch need Full Disk Access?

macOS requires it before any app can read Messages and Mail. CodeCatch reads only those two. It needs Accessibility access only if you turn on typing codes for you.

Does anything leave my Mac?

Codes and messages stay on your Mac, and passwords stay in your Keychain. CodeCatch connects to enabled mail services and checks codecatch.app for updates. Google sign-in talks to Google, and Bitwarden import talks to Bitwarden. Logos load through Google's or DuckDuckGo's favicon service and can be turned off in Privacy.

What does CodeCatch need to run?

macOS 15 or later, on Apple silicon or Intel. To get SMS codes on your Mac, turn on Text Message Forwarding on your iPhone.

Codes from text messages don’t show up. What do I check?

Your Mac only gets texts that your iPhone forwards. On your iPhone, open Settings → Apps → Messages → Text Message Forwarding and turn on your Mac. If the option or your Mac is missing, check that both use the same Apple Account (on the Mac: Messages → Settings → iMessage), then turn iMessage off and on again on the iPhone. The iPhone must also be on and online. More fixes.

What if CodeCatch misses a code?

Report it on GitHub. Send the message with the code replaced by another number. It becomes a test, so the next version catches it.
